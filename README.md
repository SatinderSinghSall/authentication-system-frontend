# 🎨 Authentication System - Frontend

Frontend for the **Full-Stack Authentication System** built with **React** and **Material UI**.

> 🚧 **Status:** Under Development

---

## 📖 Overview

This project is the frontend of a MERN Authentication System. It provides a modern, responsive user interface for user authentication and account management.

The frontend communicates with a backend REST API (coming soon) for authentication and user management.

---

## ✨ Features

### Implemented

- ✅ Login Page
- ✅ Register Page
- ✅ Forgot Password Page
- ✅ Custom 404 Page
- ✅ React Router Navigation
- ✅ Form Validation using Formik & Yup
- ✅ Password Visibility Toggle
- ✅ Responsive UI
- ✅ Material UI Components

---

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/your-username/authentication-system.git
```

Navigate to the frontend folder

```bash
cd frontend
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm start
```

Open your browser and visit

```
http://localhost:3000
```
